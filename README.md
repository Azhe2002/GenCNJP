# GenCNJP · 中日混排字形保真

本研究考察扩散模型在**文本条件与语言先验冲突**时（例如应为假名、却写成了原熟字）
的字形保真情况。我们构建了 MIXIDIOM-69 数据集，并邀请人工判断生成结果。

## 在线标注

**<https://azhe2002.github.io/GenCNJP/>**

- 匿名参与，无需登录；约 25–30 分钟，可分多次完成。
- 三个任务：身份判断（69 格）、浊点完整性（23 格）、自然度盲评（5 对 sanity check）。
- 进度保存在浏览器本地；完成后会生成一个完成码。
- 结果仅用于学术研究的汇总分析。
